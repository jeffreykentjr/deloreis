# De Lore Is

De Lore Is is a continuity engine for fictional worlds. It checks structured
claims, records the rulings that support them, and explains how those claims
stand. The kernel is deterministic and does not call a model.

This book renders the repository's source documents. Start with the
[overview](spec-00.md), then consult the [charter](charter.md),
[plan](plan.md), and [decision ledger](decisions.md). The ledger is the
authority of record. Generated reference pages come from the code.
