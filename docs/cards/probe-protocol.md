# Human-writer reading probe

The parser and examples can show that `.dli` text is accepted; they cannot show
that a writer understands what it says. This optional protocol gathers feedback
on that separate question.

Give a small group of writers the [gentle card](gentle-card.md) and a short,
unfamiliar world. Ask each person to explain which claims are settled, which
are proposed, which accounts conflict, and what evidence supports a claim.
Then ask them to find and correct one continuity problem with the documented
CLI. Avoid coaching during the task; record where the instructions or output
were unclear.

Compare the explanations with the actual query and check results. Record the
sample, materials, errors, and limitations before drawing conclusions. The
protocol is a proposal, not a claim that the study has been run or a gate on
the fiction release.
